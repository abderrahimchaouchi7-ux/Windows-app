# Math ZURO — قاعدة المعرفة الرياضية (السنة الثانية ثانوي)

قاعدة معرفة منظمة لمادة الرياضيات للسنة الثانية ثانوي (شعبة تقني رياضي، مع ملاحظات لشعبة الرياضيات)، تُستعمل كأساس لبناء نموذج **Math ZURO** القادر على شرح الطرق وحل التمارين وإنشاء تمارين جديدة.

## البنية

```
├── knowledge/

│   ├── 01_fonctions.md             ← الدوال
│   ├── 02_derivation.md            ← الاشتقاقية وتطبيقاتها
│   ├── 03_probabilites.md          ← الاحتمالات

│   ├── 06_angles_orientes_trigonometrie.md ← الزوايا الموجهة والحساب المثلثي
│   ├── 07_transformations.md       ← التحويلات النقطية (الانسحاب، التحاكي، الدوران)

└── scripts/
    └── build_index.py              ← يولّد index.jsonl
```

## صيغة المدخلات

كل عنصر معرفي له معرّف ثابت يُكتب كعنوان:

| البادئة | النوع | مثال |
|---|---|---|
| `DEF` | تعريف | `DEF-FON-04` اتجاه التغير |
| `THM` | مبرهنة / نتيجة مبرهنة | `THM-DER-04` علاقة المشتقة بالرتابة |
| `RULE` | قاعدة / خاصية / جدول مرجعي | `RULE-LIM-01` جدول النهايات الأساسية |
| `METH` | منهجية حل | `METH-PRB-01` منهجية مسألة احتمالات |
| `EX` | مثال محلول (مع الجواب) | `EX-DER-01` دراسة الدالة $x+\frac1x$ |
| `AX` | بديهية | `AX-ESP-01` بديهيات الوقوع |

الترميز: `TYPE-UNIT-NN` حيث `UNIT` اختصار المحور (FON, DER, PRB, BAR, LIM, ANG, TRA, PS, SUI, ESP, STA, TRG...).

## توليد الفهرس

```bash
python3 math-zuro/scripts/build_index.py
```

يُنتج `knowledge/index.jsonl` بحقول: `id`, `type`, `unit`, `title`, `source_file`, `content`. ويفشل إذا وُجد معرّف مكرر.

## مصادر المعلومات

- **البرنامج الرسمي:** التدرجات السنوية لمادة الرياضيات للسنة الثانية ثانوي، شعبة تقني رياضي (وزارة التربية الوطنية الجزائرية)، المتوفر في نسخ متداولة عبر الإنترنت.
- **المحتوى الرياضي:** صيغ ومبرهنات ومنهجيات معيارية في مستوى المقرر، مكتوبة بصياغة مستقلة مع أمثلة محلولة. الأمثلة تم التحقق منها حسابياً.

## ملاحظات مهمة

1. **حقوق النشر:** الكتاب المدرسي محمي بحقوق النشر، لذلك لم يُنسخ نصه حرفياً. المحتوى هنا تلخيص وإعادة صياغة للمفاهيم والقواعد.
2. **المطابقة مع الكتاب:** يُنصح بمراجعة كل وحدة مع الكتاب المدرسي المعتمد في القسم، خصوصاً:
   - ترتيب المحاور وتوزيعها الزمني (لم تُعتمد الساعات من المصادر لأنها غير واضحة).
   - المواضيع الاختيارية المعلَّم عليها بـ "إن وردت" أو "حسب المنهاج".
   - طرائق الحساب المعتمدة في الكتاب (مثل طريقة حساب الربيعيات).
3. **الأمثلة المحلولة:** كل جواب مكتوب هنا تم تحققه، لكن يُنصح بالتحقق من أي تمرين من الكتاب قبل اعتماده كبيانات تدريب.

## الخطوات التالية المقترحة

- إضافة سلسلة تمارين محلولة لكل وحدة (بصيغة JSONL) تعتمد على المداخل `METH` و`EX`.
- بناء مولّد تمارين يعتمد على القوالب الموجودة (تغيير المعطيات وإعادة حساب الجواب).
- ربط الفهرس بنموذج استرجاع (RAG) أو استعماله في تدريب/ضبط نموذج لغوي.
